# MISTURÃO

Jogo de fusão de monstrinhos, feito para jogar no celular (retrato).
Junte dois bichos, sai um terceiro herdando traços dos dois, e desça mais fundo nas fases.

**Jogar:** https://bfcorte.github.io/misturao/

Página única, offline, sem servidor. O progresso é salvo no próprio navegador do aparelho.
